FOOTBALL LIVE 24 — ملفات الموقع

مهم:
- هذه نسخة أولية بتصميم كامل ومتجاوب.
- أسماء الفرق والنتائج في الصفحة أمثلة تجريبية وليست بيانات مباريات حقيقية.
- لا تدّعي الصفحة أن النتائج مباشرة فعلاً. يلزم ربط API مرخّص وتعديل script.js قبل الإطلاق العام.
- مساحة الإعلان مجرد مكان تجريبي، وليست إعلان Google AdSense فعالاً.
- لا يوجد ضمان لقبول الموقع في AdSense أو تحقيق أرباح.

الملفات:
index.html       الصفحة الرئيسية
styles.css       التصميم
script.js        بطاقات المباريات والفلاتر
privacy.html     صفحة خصوصية أولية (راجعها وعدّلها)
contact.html     صفحة التواصل (أضف بريدك قبل النشر)

النشر المجاني المقترح عبر GitHub Pages:
1. سجّل الدخول إلى GitHub وأنشئ مستودعاً جديداً باسم football-live-24.
2. ارفع جميع الملفات الخمسة إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. في Build and deployment اختر Deploy from a branch.
5. اختر الفرع main والمجلد /(root)، ثم Save.
6. انتظر رابط الموقع الذي يعرضه GitHub Pages في صفحة Pages.

قبل تقديم طلب الإعلانات:
- استبدل كل الفرق والنتائج التجريبية بمحتوى صحيح أو احذفها.
- اربط بيانات المباريات بمصدر يسمح بعرضها تجارياً.
- أضف محتوى أصلياً ومفيداً، وحدّث سياسة الخصوصية وبريد التواصل.
- راجع شروط Google AdSense الحالية.
